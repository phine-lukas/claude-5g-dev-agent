#### 6.1.3.69 SL LBT failure MAC CE

The SL LBT failure MAC CE of one octet is identified by a MAC subheader with eLCID as specified in Table 6.2.1-2b. It has a fixed size of 8bits. The priority of the Sidelink LBT failure MAC CE is fixed to '1':

\- R<sub>i</sub>: If there is a RB set configured for the MAC entity with RB set index i as specified in TS 38.214 \[7\] and if Sidelink consistent LBT failure have been triggered and not cancelled in this RB set, the field is set to 1, otherwise the field is set to 0;

\- R: Reserved bit, set to 0.

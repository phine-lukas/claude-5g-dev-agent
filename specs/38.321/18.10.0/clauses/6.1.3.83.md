#### 6.1.3.83 Aggregated SP Positioning SRS Activation/Deactivation MAC CE

The Aggregated SP Positioning SRS Activation/Deactivation MAC CE is identified by a MAC subheader with eLCID as specified in Table 6.2.1-1b. It has a variable size with following fields:

\- Positioning SRS Aggregation ID: This field indicates one of the combinations of linked Positioning SRS *Resource Sets* corresponding to *SRS-PosResourceSetAggBW-CombinationList* or *SRS-PosRRC-InactiveAggBW-ConfigList* specified in TS 38.331 \[5\]. Value 0 corresponds to the first entry within the list *SRS-PosResourceSetAggBW-CombinationList* or *SRS-PosRRC-InactiveAggBW-ConfigList*; value 1 corresponds to the second entry within the list *SRS-PosResourceSetAggBW-CombinationList* or *SRS-PosRRC-InactiveAggBW-ConfigList* and so on;

\- C<sub>1</sub>, C<sub>2</sub>, C<sub>3</sub>: These fields indicate the activation/deactivation status of each Positioning SRS *Resource Set* that is linked for SRS for positioning bandwidth aggregation configured in *SRS-PosResourceSetLinkedForAggBW-List* or *SRS-InactivePosResourceSetLinkedForAggBW-List* specified in TS 38.331 \[5\]. C<sub>1</sub> corresponds to the first entry in *SRS-PosResourceSetLinkedForAggBW-List* or *SRS-InactivePosResourceSetLinkedForAggBW-List*, C<sub>2</sub> corresponds to the second entry in *SRS-PosResourceSetLinkedForAggBW-List* or *SRS-InactivePosResourceSetLinkedForAggBW-List* and so on. The C<sub>i</sub> field is set to 1 to indicate that the Positioning SRS *Resource Set* corresponding to C<sub>i</sub> shall be activated. The C<sub>i</sub> field is set to 0 to indicate that the Positioning SRS *Resource Set* corresponding to C<sub>i</sub> shall be de-activated;

\- S: This field indicates whether the fields Spatial Relation for Resource ID<sub>i</sub> are present. If the field is set to 1, the fields Spatial Relation for Resource ID<sub>i</sub> are present; otherwise, they are absent;

\- Spatial Relation for Resource ID<sub>i</sub>: The field Spatial Relation for Resource ID<sub>i</sub> is only present if MAC CE is used for activation, i.e. at least one of the C<sub>1</sub>, C<sub>2</sub>, and C<sub>3</sub> is set to 1. There can be as many as 16 entries of Spatial Relation for Resource ID<sub>i</sub> depending on the RRC configuration. There are 4 types of Spatial Relation for Resource ID<sub>i</sub>, which is indicated by the F (F<sub>0</sub> and F<sub>1</sub>) field within, defined as in Figure 6.1.3.36-2 to 6.1.3.36-5 in clause 6.1.3.36. Spatial Relation for Resource ID<sub>i</sub> corresponds to the spatial relation of the i<sup>th</sup> SRS resource of the SRS resources within the first activated carrier indicated by the fields C1, C2 and C3, that is aggregated with SRS resources from the other aggregated carriers according to TS 38.214 \[7\];

\- C: This field indicates whether the octets containing Resource Serving Cell ID field(s) and Resource BWP ID field(s) within the field Spatial Relation for Resource ID <sub>i</sub> are present, except for Spatial Relation Resource ID<sub>i</sub> with DL-PRS or SSB. If the combination of the linked SRS resource sets is configured by *SRS-PosResourceSetAggBW-CombinationList* and this field is set to 1, the octets containing Resource Serving Cell ID field(s) and Resource BWP ID field(s) in the field Spatial Relation for Resource ID<sub>i</sub> are present, otherwise if this field is set to 0, they are not present; if the combination of the linked SRS resource sets is configured by *SRS-PosRRC-InactiveAggBW-ConfigList*, this field shall be set to 0 and the octets containing Resource Serving Cell ID field(s) and Resource BWP ID field(s) in the field Spatial Relation for Resource ID<sub>i</sub> are not present;

\- R: Reserved bit, set to 0.

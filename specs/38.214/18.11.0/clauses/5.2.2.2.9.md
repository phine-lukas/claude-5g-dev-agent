##### 5.2.2.2.9 Further enhanced Type II port selection codebook for CJT

For 4 antenna ports {3000, 3001, …, 3003}, 8 antenna ports {3000, 3001, …, 3007}, 12 antenna ports {3000, 3001, …, 3011}, 16 antenna ports {3000, 3001, …, 3015}, 24 antenna ports {3000, 3001, …, 3023}, and 32 antenna ports {3000, 3001, …, 3031} per CSI-RS resource, the UE configured with $N_{TRP} \in \{ 1,2,3,4\}$ CSI-RS resources in a resource set for channel measurement and with higher layer parameter *codebookType* set to 'typeII-CJT-PortSelection-r18'

\- the number of CSI-RS ports for each CSI-RS resource, $P_{CSI - RS}$, is configured as in clause 5.2.2.2.4.

A set of $N_{L} \in \{ 1,2,4\}$ combinations of values of $\{\alpha_{1},\ldots,\alpha_{N_{TRP}}\}$ is configured by the higher layer parameter *paramCombination-CJT-PS-alpha-r18*, where the value of $N_{L}$ is based on the number of elements configured by the higher layer parameter *paramCombination-CJT-PS-alpha-r18* and the mapping is given in Table 5.2.2.2.9-1, with the value of $\alpha_{n}$ corresponding to CSI-RS resource $n$, for $n = 1,\ldots,N_{TRP}$. A single value of $M$ and $\beta$ is configured by the higher layer parameter *paramCombination-CJT-PS-r18*, where the mapping is given in Table 5.2.2.2.9-2. The configurable combinations of $\{\alpha_{1},\ldots,\alpha_{N_{TRP}}\}$ and $\{ M,\beta\}$ are marked with 'x' in Table 5.2.2.2.9-3.

\- The UE is not expected to be configured with *paramCombination-CJT-PS-alpha-r18* equal to

\- 2 for $N_{TRP} = 1;$ 4 for $N_{TRP} = 2;$ 2, 3 or 4 for $N_{TRP} = 3;$ when $P_{CSI - RS} \in \{ 4,12\}$,

\- 3 for $N_{TRP} = 1;$ 5 for $N_{TRP} = 2;$ 8 for $N_{TRP} = 3;$ 4 for $N_{TRP} = 4;\ $when paramCombination-CJT-PS-r18 is configured to 4 or 5 and $P_{CSI - RS} = 32$,

\- If $N_{L} > 1$, the UE is expected to select one of the $N_{L}$ configured combinations of $\{\alpha_{1},\ldots,\alpha_{N_{TRP}}\}$ and report the index of the selected combination, where the index value 0 corresponds to the first configured combination and the index value $N_{L} - 1$ corresponds to the $N_{L}$-th configured combination. The precoding matrices indicated by the PMI are determined from $\sum_{j = 1}^{N_{0}}L_{\sigma_{j}} + M$ vectors, where $\{\sigma_{1},\ldots,\sigma_{N_{0}}\}$ are the indices of the $N_{0}$ selected CSI-RS resources in increasing order, such that $1 \leq \sigma_{1} < \ldots < \sigma_{N_{0}} \leq N_{TRP}$, and $L_{\sigma_{j}} = K_{1,\sigma_{j}}/2$, $K_{1,\sigma_{j}} = \alpha_{\sigma_{j}}P_{CSI - RS}$, where $\{\alpha_{\sigma_{1}},\ \ldots,\ \alpha_{\sigma_{N_{0}}}\}$ are the corresponding values from the selected combination of $\{\alpha_{1},\ \ldots,\ \alpha_{N_{TRP}}\}$.

$K_{1,\sigma_{j}}$ ports are selected from the $P_{CSI - RS}$ ports of the $j$-th selected CSI-RS resource, for $j = 1,\ldots,N_{0}$, based on $L_{\sigma_{j}}$ vectors, $v_{m_{j}^{(i)}}$, $i = 0,1,\ldots,L_{\sigma_{j}} - 1$, which are indicated by $i_{1,2}$, where

$$i_{1,2} = \lbrack i_{1,2,1}\ \ldots i_{1,2,N_{0}}\rbrack$$

$$i_{1,2,j} \in \left\{ 0,1,\ldots,\ \begin{pmatrix}
P_{CSI - RS}/2 \\
L_{\sigma_{j}}
\end{pmatrix} - 1 \right\}$$

Let

$$m = \lbrack m_{1}\ldots\ m_{N_{0}}\rbrack$$

$$m_{j} = \lbrack m_{j}^{(0)}\ldots m_{j}^{(L_{\sigma_{j}} - 1)}\rbrack$$

$$m_{j}^{(i)} \in \left\{ 0,1,\ldots,\frac{P_{CSI - RS}}{2} - 1 \right\}$$

the index $i_{1,2,j}$, for the $j$-th selected CSI-RS resource, $j = 1,\ldots,N_{0}$, is obtained from the $L_{\sigma_{j}}$ elements of $m_{j}$, as described in Clause 5.2.2.2.7 for the indicator $i_{1,2}$, obtained from the $L$ elements of $m$. Vector $v_{m_{j}^{(i)}}$ is a $P_{CSI - RS}/2\ $-element column vector containing a value of 1 in the element of index $m_{j}^{(i)}$ and zeros elsewhere, and where the first element is the element of index 0.

\- If $\alpha_{\sigma_{j}} = 1$ for the $j$-th selected CSI-RS resource, $m_{j}^{(i)} = i$, for $i = 0,1,\ldots,\frac{P_{CSI - RS}}{2} - 1$, and $i_{1,2,j}$ is not reported.

The $M$ vectors, $\left\lbrack y_{0}^{(f)},y_{1}^{(f)},\ldots,y_{N_{3} - 1}^{(f)} \right\rbrack^{T}$, $f = 0,1,\ldots,M - 1$, are common for all the $N_{0}$ selected CSI-RS resources and are identified by $n_{3}$, where

$$n_{3} = \left\lbrack n_{3}^{(0)}\ldots\ n_{3}^{(M - 1)} \right\rbrack$$

$$n_{3}^{(f)} \in \left\{ \begin{matrix}
\{ 0\} & M = 1 \\
\left\{ 0,1,\ldots,min(N,N_{3}) - 1 \right\} & M = 2
\end{matrix} \right.\ .$$

with the indices $f \in \{ 0,\ldots,M - 1\}$ assigned such that $n_{3}^{(f)}$ increases with $f$. $n_{3}$ is indicated by the index $i_{1,6}$, when $M = 2$ and $N = 4$, where

$$i_{1,6} \in \left\{ 0,1,2 \right\}.$$

\- If $M = 1$, or $M = 2$ and $N = 2$, $i_{1,6}$ is not reported.

\- If $M = 2$ and $N = 4$, the nonzero offset between $n_{3}^{(0)}$ and $n_{3}^{(1)}$ is reported with $i_{1,6}$ assuming that $n_{3}^{(0)}$ (reference for the offset) is 0. The nonzero offset values are mapped to the index values of $i_{1,6}$ in increasing order with offset value 1 mapped to index value '0'.

The $M$ vectors' elements are given by

$${y_{t}^{(f)} = e}^{j\frac{2\pi tn_{3}^{(f)}}{N_{3}}}$$

for $t = 0,1,\ldots N_{3} - 1$, and $f = 0,\ldots,M - 1$.

If the higher layer parameter *codebookMode* is set to 'mode1', an offset $d_{j}$ is reported for the $j$-th selected CSI-RS resource, with $j = 2,\ldots,N_{0}$, relative to the first of the $N_{0}$ selected CSI-RS resources. $$\psi = \lbrack\psi_{2}\ldots\ \psi_{N_{0}}\rbrack$$

$$\psi_{j} = \frac{d_{j}}{O_{3}}$$

If *codebookMode* is set to 'mode2', the offset indicator, $i_{1,9}$, is not reported and $\psi_{j} = 0$ for $j = 1,\ldots,N_{0}$.

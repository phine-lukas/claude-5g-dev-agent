#### 9.2.3.187 Average Packet Delay

This IE indicates the RAN part of the average packet delay in the UL and DL directions.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| Average Packet Delay UL | M |  | INTEGER (0.. 10000) | Corresponds to the Packet delay per-UE as specified in TS 28.558 [58], clause 6.3.1.1. Unit: 0.1 millisecond |
| Average Packet Delay DL | M |  | INTEGER (0.. 10000) | Corresponds to the Packet delay per-UE as specified in TS 28.558 [58], clause 6.3.1.1. Unit: 0.1 millisecond |
<!-- /table -->

#### 9.2.3.180 Cell Based UE Trajectory Prediction

The *Cell Based UE Trajectory Prediction* IE contains information related to NG-RAN cells where the UE is predicted to connect.

<!-- table -->
| IE/Group Name | Presence | Range | IE Type and Reference | Semantics Description |
| Cell Based UE Trajectory Prediction |  | 1 |  | List of cells where the UE is predicted to connect, in chronological order. The first predicted cell added to the top of this list, is the cell in the target node where the UE will move to after the serving cell at the source node. |
| &gt;Predicted UE Trajectory Item |  | 1..&lt;maxnoofCellsTrajectoryPredict&gt; |  |  |
| &gt;&gt;Predicted Trajectory Cell Information | M |  | 9.2.3.181 |  |
<!-- /table -->

| Range bound                   | Explanation                                                                   |
|-------------------------------|-------------------------------------------------------------------------------|
| maxnoofCellsTrajectoryPredict | Maximum number of cells that can be predicted for UE trajectory. Value is 16. |

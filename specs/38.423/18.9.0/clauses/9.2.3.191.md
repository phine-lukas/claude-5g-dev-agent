#### 9.2.3.191 CAG List for MDT

This IE is used to identify the list of Public Network Integrated NPNs for MDT.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| CAG List for MDT |  | 1 |  | For logged MDT, this list contains a maximum of 144 Public Network Integrated NPNs with a maximum of 12 different PLMN identities, configurable to the CAG-ConfigList IE defined in TS 38.331 [10] where a PLMN Identity may be repeated more than once. |
| &gt;CAG List for MDT Item |  | 1..&lt; maxnoofCAGforMDT &gt; |  |  |
| &gt;&gt;PLMN Identity | M |  | 9.2.2.4 |  |
| &gt;&gt;CAG-Identifier | M |  | 9.2.2.66 |  |
<!-- /table -->

| Range bound      | Explanation                                              |
|------------------|----------------------------------------------------------|
| maxnoofCAGforMDT | Maximum no. of CAG IDs for MDT area scope. Value is 256. |

#### 9.2.3.88 Volume Timed Report List

This IE provides information on the data usage.

| IE/Group Name | Presence | Range | IE type and reference | Semantics description |

| &gt;Start Timestamp | M |  | OCTET STRING (SIZE(4)) | UTC time encoded in the same format as the first four octets of the 64-bit timestamp format as defined in section 6 of IETF RFC 5905 [37]. | &gt;End Timestamp | M |  | OCTET STRING (SIZE(4)) | UTC time encoded in the same format as the first four octets of the 64-bit timestamp format as defined in section 6 of IETF RFC 5905 [37]. It indicates the end time of the collecting period of the included Usage Count UL IE and Usage Count DL IE. |
| &gt;Usage Count UL | M |  | INTEGER (0..2 64 -1) | The unit is: octets. |
| &gt;Usage Count DL | M |  | INTEGER (0..2 64 -1) | The unit is: octets. |

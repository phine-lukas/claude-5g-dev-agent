#### 9.2.3.246 Semi-persistent Positioning Information

This IE contains semi-persistent positioning information to notify the activation or deactivation of semi-persistent SRS transmission for area-specific SRS configuration.

|                                               |          |                                      |                       |                                                                                                                                                                         |
|-----------------------------------------------|----------|--------------------------------------|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IE/Group Name                                 | Presence | Range                                | IE type and reference | Semantics description                                                                                                                                                   |
| SRS Transmission Type                         | M        | ENUMERATED (activate, deactivate, …) |                       |                                                                                                                                                                         |
| SRS Resource Set ID                           | M        | OCTET STRING                         |                       | Includes the *SRS Resource Set ID* IE, as defined in TS 38.455 \[49\].                                                                                                  |
| SRS Spatial Relation                          | O        | OCTET STRING                         |                       | Includes the *SRS Spatial Relation* IE, as defined in TS 38.455 \[49\]. Applicable only if the *SRS Transmission Type* IE is set to "activate".                         |
| Spatial Relation Information per SRS Resource | O        | OCTET STRING                         |                       | Includes the *Spatial Relation Information per SRS Resource* IE as defined in TS 38.455 \[49\]. Applicable only if the *SRS Transmission Type* IE is set to "activate". |

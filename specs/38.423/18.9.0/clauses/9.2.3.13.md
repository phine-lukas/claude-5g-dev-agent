#### 9.2.3.13 Packet Error Rate

This IE indicates the Packet Error Rate for a QoS flow.

| IE/Group Name | Presence | Range | IE type and reference | Semantics description                                                                       |
|---------------|----------|-------|-----------------------|---------------------------------------------------------------------------------------------|
| Scalar        | M        |       | INTEGER (0..9,…)      | The packet error rate is expressed as Scalar \* 10<sup>-k</sup>, whereas k is the Exponent. |
| Exponent      | M        |       | INTEGER (0..9, ...)   |                                                                                             |

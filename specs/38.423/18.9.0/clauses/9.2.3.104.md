#### 9.2.3.104 Alternative QoS Parameters Set Notify Index

This IE indicates the QoS parameters set which can currently be fulfilled.

| IE/Group Name                               | Presence | Range | IE type and reference | Semantics description                                                                                                                                                                                                                                             |
|---------------------------------------------|----------|-------|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Alternative QoS Parameters Set Notify Index | M        |       | INTEGER (0..8, ...)   | Indicates the index of the item within the *Alternative QoS Parameters Set List* IE corresponding to the currently fulfilled alternative QoS parameters set. Value 0 indicates that NG-RAN cannot even fulfil the lowest priority alternative QoS parameters set. |

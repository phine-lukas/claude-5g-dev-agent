#### 9.2.3.17 UE Aggregate Maximum Bit Rate

The UE Aggregate Maximum Bitrate is applicable for all Non-GBR QoS flows per UE which is defined for the Downlink and the Uplink direction and a subscription parameter provided by the AMF to the NG-RAN.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| UE Aggregate Maximum Bit Rate |  | 1 |  | Applicable for Non-GBR QoS flows. |
| &gt;UE Aggregate Maximum Bit Rate Downlink | M |  | Bit Rate 9.2.3.4 | This IE indicates the UE Aggregate Maximum Bit Rate as specified in TS 23.501 [7] in the downlink direction. |
| &gt;UE Aggregate Maximum Bit Rate Uplink | M |  | Bit Rate 9.2.3.4 | This IE indicates the UE Aggregate Maximum Bit Rate as specified in TS 23.501 [7] in the uplink direction. |

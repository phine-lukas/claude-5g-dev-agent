#### 9.2.3.210 User Plane Failure Indication

This IE is used to notify the S-NG-RAN node that a user plane failure occurred over NG-U interface.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| User Plane Failure Type | M |  | ENUMERATED (GTP-U Error Indication Received, UP Path Failure, …) | Indicates the type of NG-U failure. |
| UL NG-U UP TNL Information | M |  | UP Transport Layer Information 9.2.3.30 | Identifies the NG-U transport bearer at the UPF node. |
| DL NG-U UP TNL Information | M |  | UP Transport Layer Information 9.2.3.30 | Identifies the NG-U transport bearer at the S-NG-RAN node. |
<!-- /table -->

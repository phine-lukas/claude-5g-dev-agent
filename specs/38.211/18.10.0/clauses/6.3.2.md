#### 6.3.2.5 PUCCH format 2

##### 6.3.2.5.1 Scrambling

The block of bits $b(0),\ldots,b(M_{\text{bit}} - 1)$, where $M_{\text{bit}}$ is the number of bits transmitted on the physical channel, shall be scrambled prior to modulation, resulting in a block of scrambled bits $\widetilde{b}(0),\ldots,\widetilde{b}(M_{\text{bit}} - 1)$ according to the following pseudo code

Set *i* = 0

while $i < M_{\text{bit}}$

if $b(i) = y$ // UCI placeholder bits

$\widetilde{b}(i) = \ \widetilde{b}(i - 1)$

else

$\widetilde{b}(i) = \left( b(i) + c(i) \right)\ \text{mod}\ 2$

end if

*i* = *i* + 1

end while

where y is the tag defined in \[4, TS38.212\] and the scrambling sequence $c(i)$ is given by clause 5.2.1. The scrambling sequence generator shall be initialized with

$$c_{\text{init}} = n_{\text{RNTI}} \bullet 2^{15} + n_{\text{ID}}$$

\- $n_{\text{ID}} = N_{\text{ID}}^{\text{cell}}$ otherwise

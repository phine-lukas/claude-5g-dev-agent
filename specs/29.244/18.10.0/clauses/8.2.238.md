### 8.2.238 Extended DL Buffering Notification Policy

Extended DL Buffering Notification Policy is coded as depicted in Figure 8.2.238-1.

|     |            | Bits                                                       |     |     |     |     |     |     |      |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|------|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1    |     |
|     | 1 to 2     | Type = 346 (decimal)                                       |     |     |     |     |     |     |      |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |      |     |
|     | 5          | Spare                                                      |     |     |     |     |     |     | EDBN |     |
|     | k to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |      |     |

Figure 8.2.238-1: Extended DL Buffering Notification Policy

The following flags are coded within Octet 5:

\- Bit 1 – EDBN (Extended DL Buffer Notification): This bit shall be set to "1" when the UP function shall send DL packet notification for the duration indicated by the DL Buffering Duration to report the arrival of the first buffered DL packet for each QoS flow for a given FAR. (see clause 7.5.4.11 and 7.5.9.2).

\- Bit 2 to 8 are spare and reserved for future use, shall be set to "0" by the sender and discarded by the receiver.

### 8.2.182 User Plane Node Management Information Container

The User Plane Node Management Information Container IE shall be encoded as shown in Figure 8.2.182-1. It contains an opaque container of User Plane Node management information.

|     |            | Bits                                   |     |     |     |     |     |     |     |     |
|-----|------------|----------------------------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets     | 8                                      | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2     | Type = 266 (decimal)                   |     |     |     |     |     |     |     |     |
|     | 3 to 4     | Length = n                             |     |     |     |     |     |     |     |     |
|     | 5 to (n+4) | User Plane Node Management Information |     |     |     |     |     |     |     |     |

Figure 8.2.182-1: User Plane Node Management Information Container

The User Plane Node Management Information field shall be encoded as an Octet String. It shall encode a User plane node management message defined in clause 9 of 3GPP TS 24.539 \[63\].

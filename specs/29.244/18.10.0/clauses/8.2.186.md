### 8.2.186 RAT Type

The RAT Type IE indicates the RAT type for the PFCP Session. The RAT Type IE type shall be encoded as shown in Figure 8.2.186-1.

|     |            | Bits                                                       |     |     |     |     |     |     |     |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2     | Type = 275                                                 |     |     |     |     |     |     |     |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |     |     |
|     | 5          | RAT Type                                                   |     |     |     |     |     |     |     |     |
|     | 6 to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |     |     |

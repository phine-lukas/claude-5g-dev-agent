### 8.2.241 RTP Header Extension Additional Information

The RTP Header Extension Additional Information provides additional information on the RTP Header Extension. It shall be coded as depicted in Figure 8.2.241-1.

|     |            | **Bits**                                                   |       |       |       |       |       |        |       |     |
|-----|------------|------------------------------------------------------------|-------|-------|-------|-------|-------|--------|-------|-----|
|     | **Octets** | **8**                                                      | **7** | **6** | **5** | **4** | **3** | **2**  | **1** |     |
|     | 1 to 2     | Type = 349 (decimal)                                       |       |       |       |       |       |        |       |     |
|     | 3 to 4     | Length = n                                                 |       |       |       |       |       |        |       |     |
|     | 5          | Spare                                                      |       |       |       |       |       | PSSAI  | FI    |     |
|     | 6          | Spare                                                      |       |       |       |       | PSSA  | Format |       |     |
|     | 7 to (n+4) | These octet(s) is/are present only if explicitly specified |       |       |       |       |       |        |       |     |

Figure 8.2.241-1: RTP Extension Header Additional Information

The following flags are coded within Octet 5:

\- Bit 1 – FI (Format Indication): If this bit is set to "1", it indicates that the Format field in octet 6 indicates the RTP header extension format. If this bit is set to "0", the format field in octet 6 shall be coded as all "0" and be ignored by the receiver.

\- Bit 2 – PSSAI (PDU Set Size Active Indication): If this bit is set to "1", it indicates that the PSSA field in octet 6 indicates whether the PDU Set size in bytes is present in the RTP header extension of every RTP packet. If this bit is set to "0", the PSSA field in octet 6 shall be coded as all "0" and be ignored by the receiver.

\- Bit 3 to 8 Spare, for future use and set to "0".

The Format field in octet 6 shall be encoded as defined in Table 8.2.241-1.

Table 8.2.241-1: Format field

<!-- table -->
| Value (Decimal) | Format field |
| 1 | 1-byte (short) format is used |
| 2 | 2-byte (long) format is used |
| 0, 3 | Spare, for future use. |
<!-- /table -->

The PDU Set Size Active (PSSA) field in octet 6 shall be encoded as "1" if the PSSAI flag is set to 1 and the PDU Set Size is present in the RTP header extension of every RTP packet, and as "0" otherwise.

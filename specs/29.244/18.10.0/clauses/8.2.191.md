### 8.2.191 Called Number

The Called Number IE type shall be encoded as shown in Figure 8.2.191-1. It contains a Called Number value which may contain a DNN/APN. (see 3GPP TS 29.061 \[39\]).

|     |            | Bits                 |     |     |     |     |     |     |     |     |
|-----|------------|----------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets     | 8                    | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2     | Type = 283 (decimal) |     |     |     |     |     |     |     |     |
|     | 3 to 4     | Length = n           |     |     |     |     |     |     |     |     |
|     | 5 to (n+4) | Called Number value  |     |     |     |     |     |     |     |     |

Figure 8.2.191-1: Called Number

The Called Number value shall be encoded in UTF8String format.

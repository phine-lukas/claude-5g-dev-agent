### 8.2.243 N6 Routing Information

The N6 Routing Information IE type shall be encoded as shown in Figure 8.2.243-1. It contains N6 tunneling information.

|     |             | Bits                                                       |     |     |       |       |     |       |       |     |
|-----|-------------|------------------------------------------------------------|-----|-----|-------|-------|-----|-------|-------|-----|
|     | Octets      | 8                                                          | 7   | 6   | 5     | 4     | 3   | 2     | 1     |     |
|     | 1 to 2      | Type = 351 (decimal)                                       |     |     |       |       |     |       |       |     |
|     | 3 to 4      | Length = n                                                 |     |     |       |       |     |       |       |     |
|     | 5           | Spare                                                      |     | DPO | DIPV6 | DIPV4 | SPO | SIPV6 | SIPV4 |     |
|     | m to (m+3)  | Source IPv4 address                                        |     |     |       |       |     |       |       |     |
|     | p to (p+15) | Source IPv6 address                                        |     |     |       |       |     |       |       |     |
|     | q to (q+1)  | Source Port Number                                         |     |     |       |       |     |       |       |     |
|     | r to (r+3)  | Destination IPv4 address                                   |     |     |       |       |     |       |       |     |
|     | s to (s+15) | Destination IPv6 address                                   |     |     |       |       |     |       |       |     |
|     | t to (t+1)  | Destination Port Number                                    |     |     |       |       |     |       |       |     |
|     | k to (n+4)  | These octet(s) is/are present only if explicitly specified |     |     |       |       |     |       |       |     |

Figure 8.2.243-1: N6 Routing Information

The following flags are coded within Octet 5:

\- Bit 1 – SIPV4: If this bit is set to "1", then the Source IPv4 address field shall be present in the N6 Routing Information, otherwise the Source IPv4 address field shall not be present.

\- Bit 2 – SIPV6: If this bit is set to "1", then the Source IPv6 address field shall be present in the N6 Routing Information, otherwise the Source IPv6 address field shall not be present.

\- Bit 3 – SPO: If this bit is set to "1", then the Source Port Number field shall be present in the N6 Routing Information, otherwise the Source Port Number field shall not be present.

\- Bit 4 – DIPV4: If this bit is set to "1", then the Destination IPv4 address field shall be present in the N6 Routing Information, otherwise the Destination IPv4 address field shall not be present.

\- Bit 5 – DIPV6: If this bit is set to "1", then the Destination IPv6 address field shall be present in the N6 Routing Information, otherwise the Destination IPv6 address field shall not be present.

\- Bit 6 – DPO: If this bit is set to "1", then the Destination Port Number field shall be present in the N6 Routing Information, otherwise the Destination Port Number field shall not be present.

\- Bit 7 - 8 Spare, for future use and set to "0".

Octets "m to (m+3)" or "p to (p+15)" (Source IPv4 address / Source IPv6 address fields) and Octets "r to (r+3)" or "s to (s+15)" (Destination IPv4 address / Destination IPv6 address fields), if present, shall contain the address value.

When present, the Destination Port Number field or the Source Port Number field shall contain the destination or source Port Number respectively to set in the UDP header of the outgoing packet.

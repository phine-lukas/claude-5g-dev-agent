### 8.2.195 Maximum Receive Unit

The Maximum Receive Unit shall be encoded as shown in Figure 8.2.195-1. The Maximum Receive Unit value shall contain the link MTU size value received from the UE via the Protocol Configuration Options (see 3GPP TS 24.008 \[5\]).

|     |        | Bits                       |     |     |     |     |     |     |     |     |
|-----|--------|----------------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets | 8                          | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2 | Type = 287 (decimal)       |     |     |     |     |     |     |     |     |
|     | 3 to 4 | Length = 2                 |     |     |     |     |     |     |     |     |
|     | 5 to 6 | Maximum Receive Unit value |     |     |     |     |     |     |     |     |

Figure 8.2.195-1: Maximum Receive Unit

The Maximum Receive Unit value shall be encoded as two octet's binary integer value.

### 7.5.6 PFCP Session Deletion Request

The PFCP Session Deletion Request shall be sent over the Sxa, Sxb, Sxc and N4 interface by the CP function to request the UP function to delete the PFCP session. The PFCP Header for Session Related Messages shall contain the F-SEID identifying the PFCP session (see clause 6.3.4.2).

### 8.2.244 URI

The URI IE type shall be encoded as shown in Figure 8.2.244-1.

| .   |          | Bits                 |     |     |     |     |     |     |     |     |
|-----|----------|----------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets   | 8                    | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2   | Type = 352 (decimal) |     |     |     |     |     |     |     |     |
|     | 3 to 4   | Length = n           |     |     |     |     |     |     |     |     |
|     | 5 to n+4 | URI                  |     |     |     |     |     |     |     |     |

Figure 8.2.244 -1: URI

The URI field in octets 5 to (n+4) shall contain an octet string representing the URI formatted according to IETF RFC 3986 \[71\].

### 8.2.225 MPQUIC Control Information

The MPTCP Control Information IE shall provide details of the required MPQUIC functionality. It shall be encoded as shown in Figure 8.2.a-1.

|     |            | Bits                                                       |     |     |     |     |     |     |      |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|------|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1    |     |
|     | 1 to 2     | Type = 330 (decimal)                                       |     |     |     |     |     |     |      |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |      |     |
|     | 5          | Spare                                                      |     |     |     |     |     |     | CUDP |     |
|     | m to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |      |     |

Figure 8.2.225-1: MPQUIC Control Information

The following flags are coded within Octet 5:

\- Bit 1– CUDP (CONNECT-UDP): If this bit is set to "1", it indicates that the proxy type of required MPQUIC is "connect-udp" (see clause 5.32.6.2.2 of 3GPP TS 23.501 \[28\]) and the UPF shall allocate relevant resource as specified in clause 5.20.2A.1

\- Bit 2 to 8 Spare, for future use and set to "0".

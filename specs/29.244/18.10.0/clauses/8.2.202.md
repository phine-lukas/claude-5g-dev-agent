### 8.2.202 Event Notification URI

The Event Notification URI IE type shall be encoded as shown in Figure 8.2.202-1.

| .   |          | Bits                   |     |     |     |     |     |     |     |     |
|-----|----------|------------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets   | 8                      | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2   | Type = 296 (decimal)   |     |     |     |     |     |     |     |     |
|     | 3 to 4   | Length = n             |     |     |     |     |     |     |     |     |
|     | 5 to n+4 | Event Notification URI |     |     |     |     |     |     |     |     |

Figure 8.2.202-1: Event Notification URI

The Event Notification URI field in octets 5 to (n+4) shall contain an octet string representing the Event Notification URI (i.e. string providing an URI formatted according to IETF RFC 3986 \[71\]) to be used for sending the UPF event notifications.

### 8.2.272 Reporting Control Information

The Reporting Control Information IE shall be encoded as shown in Figure 8.2.272-1.

|     |            | Bits                                                       |     |     |     |     |     |     |      |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|------|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1    |     |
|     | 1 to 2     | Type = 389 (decimal)                                       |     |     |     |     |     |     |      |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |      |     |
|     | 5          | Spare                                                      |     |     |     |     |     |     | UELM |     |
|     | 6 to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |      |     |

Figure 8.2.272-1: Reporting Control Information

The following bits within Octet 5 shall indicate:

\- Bit 1 – UELM (UE Level Measurement): if this flag is set to "1", it indicates that QoS monitoring is triggered for UE level measurement and that corresponding measurements shall be sent to the IP Address of Trace Collection Entity (when using file-based reporting) or the Trace Collection Entity URI (when using streaming-based reporting) as specified in clause 5.15A.

\- Bits 2 to 8 – Spare, for future use and set to "0".

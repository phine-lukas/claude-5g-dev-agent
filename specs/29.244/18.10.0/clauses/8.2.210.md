### 8.2.210 MBS Unicast Parameters ID

The MBS Unicast Parameters ID IE type shall be encoded as shown in Figure 8.2.210-1. It shall contain a MBS Unicast Parameters ID.

|     |            | Bits                                                       |     |     |     |     |     |     |     |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2     | Type = 309 (decimal)                                       |     |     |     |     |     |     |     |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |     |     |
|     | 5 to 6     | MBS Unicast Parameters ID value                            |     |     |     |     |     |     |     |     |
|     | 7 to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |     |     |

Figure 8.2.210-1: MBS Unicast Parameters ID

The MBS Unicast Parameters ID value field shall be encoded as an Unsigned16 binary integer value.

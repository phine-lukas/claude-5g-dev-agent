### 8.2.231 Measurement Indication

The Measurement Indication IE shall be encoded as shown in Figure 8.2.231-1.

|     |            | Bits                                                       |     |     |     |     |     |     |      |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|------|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1    |     |
|     | 1 to 2     | Type = 337 (decimal)                                       |     |     |     |     |     |     |      |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |      |     |
|     | 5          | Spare                                                      |     |     |     |     |     |     | DQFI |     |
|     | m to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |      |     |

Figure 8.2.231-1: Measurement Indication

The following flags are coded within Octet 5:

\- Bit 1 – DQFI (Default QoS Flow Indication): If this bit is set to "1", it indicates that the UPF is requested to perform QoS Monitoring measurements on the QoS flow associated with the default QoS rule and the UPF shall include the same indication in the corresponding QoS Monitoring Measurement report (see clause 4.15.4.5.1 of 3GPP TS 23.502 \[29\]).

\- Bit 2 to 8 Spare, for future use and set to "0".

### 8.2.42 Measurement Period

The Measurement Period IE contains the period, in seconds, for generating periodic usage reports or the periodic QoS monitoring reports, or the period used for detecting and reporting a QoS monitoring measurement failure. It shall be encoded as shown in Figure 8.2.42-1.

|     |            | Bits                                                       |     |     |     |     |     |     |     |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2     | Type = 64 (decimal)                                        |     |     |     |     |     |     |     |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |     |     |
|     | 5 to 8     | Measurement Period                                         |     |     |     |     |     |     |     |     |
|     | 9 to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |     |     |

Figure 8.2.42-1: Measurement Period

The Measurement Period field shall be encoded as an Unsigned32 binary integer value.

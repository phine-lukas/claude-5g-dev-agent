### 8.2.198 Group Id

The Group Id IE type shall be encoded as shown in Figure 8.2.198-1. It shall contain an octet string as a global unique identifier for a group and it may be encoded using the same mechanism for the NfInstanceId as specified in 3GPP TS 29.571 \[61\].

| .   |          | Bits                 |     |     |     |     |     |     |     |     |
|-----|----------|----------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets   | 8                    | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2   | Type = 291 (decimal) |     |     |     |     |     |     |     |     |
|     | 3 to 4   | Length = n           |     |     |     |     |     |     |     |     |
|     | 5 to n+4 | Group Id             |     |     |     |     |     |     |     |     |

## 5.1 Introduction

The architecture reference model with Control and User Plane Separation of EPC nodes is described in clause 4.2 of 3GPP TS 23.214 \[2\].

The architecture reference model with SMF and UPF of 5GC nodes is described in clause 4.2 of 3GPP TS 23.501 \[28\].

The architecture reference model with MB-SMF and MB-UPF of 5GC nodes is described in clause 6.7 of 3GPP TS 23.247 \[72\].

This clause specifies the high level principles of the PFCP protocol and describe how 3GPP functionalities are realised on the Sxa, Sxb, Sxc, N4 and N4mb reference points, e.g. Packet Forwarding, Policy and Charging Control, Lawful Interception.

### 8.2.245 UE Level Measurements Configuration

The UE Level Measurements Configuration IE shall be encoded as shown in Figure 8.2.245-1. It contains the 5GC UE level measurements configuration parameters to apply for the PFCP session.

|     |            | Bits                                                       |     |     |     |     |     |     |     |     |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |     |
|     | 1 to 2     | Type = 353 (decimal)                                       |     |     |     |     |     |     |     |     |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |     |     |     |
|     | 5          | Job Type                                                   |     |     |     |     |     |     |     |     |     |
|     | 6          | Number of Measurement Types (k)                            |     |     |     |     |     |     |     |     |     |
|     | 7          | Measurement Type value 1                                   |     |     |     |     |     |     |     |     |     |
|     | 8          | Measurement Type value 2                                   |     |     |     |     |     |     |     |     |     |
|     | …          | …                                                          |     |     |     |     |     |     |     |     |     |
|     | 7+k-1      | Measurement Type value k                                   |     |     |     |     |     |     |     |     |     |
|     | m to m+2   | Time Period                                                |     |     |     |     |     |     |     |     |     |
|     | p to (n-4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |     |     |     |

Figure 8.2.245-1: UE Level Measurements Configuration

Octets 5 represent the Job type for 5GC UE level measurements as defined in 3GPP TS 32.422 \[35\]. It shall be encoded as defined in Table 8.2.245-1.

Table 8.2.245-1: Job Type values

| Job Type                            | Values (Decimal) |
|-------------------------------------|------------------|
| \<reserved\>                        | 0                |
| 5GC UE Level Measurements only      | 1                |
| Trace and 5GC UE Level Measurements | 2                |
| Spare, for future use               | 3-255            |

The Number of Measurement Types shall indicate the total number of the Measurement Type values. Each subsequent Octet after the Number of Measurement Types shall carry one Measurement Type value as defined in 3GPP TS 28.558 \[88\]. The Measurement Type value shall be encoded as defined in Table 8.2.245-2.

Table 8.2.245-2: Measurement Type values

| Measurement Type                                                             | Values (Decimal) |
|------------------------------------------------------------------------------|------------------|
| \<reserved\>                                                                 | 0                |
| Average DL packet delay between PSA UPF and UE for a QoS flow                | 1                |
| Average UL packet delay between PSA UPF and UE for a QoS flow (excluding D1) | 2                |
| Average UL packet delay between PSA UPF and UE for a QoS flow (including D1) | 3                |
| Average UL packet delay between PSA UPF and NG-RAN for a QoS flow            | 4                |
| Average DL packet delay between PSA UPF and NG-RAN for a QoS flow            | 5                |
| Spare, for future use                                                        | 6-255            |

Time Period Field Value shall indicate the period time for every Trace Recording Session of 5GC UE level measurement as defined in 3GPP TS 32.422 \[35\]. It shall be encoded as binary integer value in 3 octets with a unit second.

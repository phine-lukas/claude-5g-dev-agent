### 8.2.236 RTP Payload Type

The RTP Payload Type indicates the payload type of RTP packets. It shall be coded as depicted in Figure 8.2.336-1.

|     |            | **Bits**             |       |       |       |       |       |       |       |     |
|-----|------------|----------------------|-------|-------|-------|-------|-------|-------|-------|-----|
|     | **Octets** | **8**                | **7** | **6** | **5** | **4** | **3** | **2** | **1** |     |
|     | 1 to 2     | Type = 344 (decimal) |       |       |       |       |       |       |       |     |
|     | 3 to 4     | Length = 1           |       |       |       |       |       |       |       |     |
|     | 5          | Payload Type         |       |       |       |       |       |       |       |     |

Figure 8.2.236-1: RTP Payload Type

The Payload Type field shall encode the (S)RTP payload type, as an integer between (and including) 0 and 127.

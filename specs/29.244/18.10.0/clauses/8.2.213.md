### 8.2.213 Area Session ID

The Area Session ID together with the MBS Session Identifier uniquely identifies the service area part of the content data of a location dependent MBS service (see clause 30.3 of 3GPP TS 23.003 \[2\]). It shall be coded as specified in Figure 8.2.213-1.

|     |        | Bits                  |     |     |     |     |     |     |     |     |
|-----|--------|-----------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets | 8                     | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2 | Type = 314 (decimal)  |     |     |     |     |     |     |     |     |
|     | 3 to 4 | Length = 2            |     |     |     |     |     |     |     |     |
|     | 5 to 6 | Area Session ID value |     |     |     |     |     |     |     |     |

Figure 8.2.213-1: Area Session ID

The Area Session ID value shall be encoded as an Unsigned16 binary integer value.

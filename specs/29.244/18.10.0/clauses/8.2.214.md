### 8.2.214 DSCP to PPI Mapping Information

The DSCP to PPI Mapping Information IE shall be encoded as shown in Figure 8.2.214-1. It contains the mapping from DSCP(s) to a PPI.

|     |                | Bits                                                       |     |              |     |     |           |     |     |     |
|-----|----------------|------------------------------------------------------------|-----|--------------|-----|-----|-----------|-----|-----|-----|
|     | Octets         | 8                                                          | 7   | 6            | 5   | 4   | 3         | 2   | 1   |     |
|     | 1 to 2         | Type = 317 (decimal)                                       |     |              |     |     |           |     |     |     |
|     | 3 to 4         | Length = n                                                 |     |              |     |     |           |     |     |     |
|     | 5              | Spare                                                      |     |              |     |     | PPI Value |     |     |     |
|     | 6              | Spare                                                      |     | DSCP Value 1 |     |     |           |     |     |     |
|     | 7              | Spare                                                      |     | DSCP Value 2 |     |     |           |     |     |     |
|     | ...            | Spare                                                      |     | ...          |     |     |           |     |     |     |
|     | (5+x)          | Spare                                                      |     | DSCP Value x |     |     |           |     |     |     |
|     | (6+x) to (n+4) | These octet(s) is/are present only if explicitly specified |     |              |     |     |           |     |     |     |

Figure 8.2.214-1: DSCP to PPI Mapping Information

The PPI Value in octet 5 shall be encoded as a value between 0 and 7, as specified in clause 5.5.3.7 of 3GPP TS 38.415 \[34\].

The DSCP Value 1 to x, in octet 6 to octet (5+x), where X shall not be larger than 63, shall be encoded as the DSCP in TOS (IPv4) or TC (IPv6) information (see IETF RFC 2474 \[13\]).

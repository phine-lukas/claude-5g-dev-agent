### 8.2.190 Calling Number

The Calling Number IE type shall be encoded as shown in Figure 8.2.190-1. It contains a Calling Number value which may contain a MSISDN (see 3GPP TS 29.061 \[39\]).

|     |            | Bits                 |     |     |     |     |     |     |     |     |
|-----|------------|----------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets     | 8                    | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2     | Type = 282 (decimal) |     |     |     |     |     |     |     |     |
|     | 3 to 4     | Length = n           |     |     |     |     |     |     |     |     |
|     | 5 to (n+4) | Calling Number value |     |     |     |     |     |     |     |     |

Figure 8.2.190-1: Calling Number

The Calling Number value shall be encoded in UTF8String format.

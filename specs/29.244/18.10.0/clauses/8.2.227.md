### 8.2.227 Transport Mode

The transport mode IE shall be encoded as shown in Figure 8.2.227-1. It indicates the transport mode for transmitting a UDP flow.

|     |            | Bits                                                       |     |     |     |                      |     |     |     |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|----------------------|-----|-----|-----|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4                    | 3   | 2   | 1   |     |
|     | 1 to 2     | Type = 333 (decimal)                                       |     |     |     |                      |     |     |     |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |                      |     |     |     |     |
|     | 5          | Spare                                                      |     |     |     | Transport Mode Value |     |     |     |     |
|     | 6 to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |                      |     |     |     |     |

Figure 8.2.227-1: Transport Mode

The Transport Mode value shall be encoded as a 4 bits binary integer as specified in Table 8.2.e-1.

Table 8.2.227-1: Transport Mode value

| Transport Mode Value | Values (Decimal) |
| Datagram mode 1 | 0 |
| Datagram mode 2 | 1 |
| Stream mode | 2 |
| Spare | 3 to 15 |

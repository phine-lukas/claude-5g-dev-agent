### 8.2.188 LNS Address

The LNS Address IE shall contain an IPv4/IPv6 address. It shall be encoded as shown in Figure 8.2.188-1.

|     |            | Bits                                                       |     |     |     |     |     |     |     |     |
|-----|------------|------------------------------------------------------------|-----|-----|-----|-----|-----|-----|-----|-----|
|     | Octets     | 8                                                          | 7   | 6   | 5   | 4   | 3   | 2   | 1   |     |
|     | 1 to 2     | Type = 280 (decimal)                                       |     |     |     |     |     |     |     |     |
|     | 3 to 4     | Length = n                                                 |     |     |     |     |     |     |     |     |
|     | 5 to o     | LNS Address value                                          |     |     |     |     |     |     |     |     |
|     | m to (n+4) | These octet(s) is/are present only if explicitly specified |     |     |     |     |     |     |     |     |

Figure 8.2.188-1: LNS Address

If the LNS Address is an IPv4 address, the LNS Address value length shall be "4".

If the LNS Address is an IPv6 address, the LNS Address value length shall be "16".

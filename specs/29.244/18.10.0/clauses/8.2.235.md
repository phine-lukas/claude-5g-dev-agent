### 8.2.235 RTP Header Extension ID

The RTP Header Extension ID IE indicates the ID of the RTP header extension. It shall be coded as depicted in Figure 8.2.235-1.

|     |            | **Bits**                |       |       |       |       |       |       |       |     |
|-----|------------|-------------------------|-------|-------|-------|-------|-------|-------|-------|-----|
|     | **Octets** | **8**                   | **7** | **6** | **5** | **4** | **3** | **2** | **1** |     |
|     | 1 to 2     | Type = 343 (decimal)    |       |       |       |       |       |       |       |     |
|     | 3 to 4     | Length = 1              |       |       |       |       |       |       |       |     |
|     | 5          | RTP Header Extension ID |       |       |       |       |       |       |       |     |

Figure 8.2.235-1: RTP Header Extension ID

The RTP Header Extension ID field shall be encoded as a decimal value in the range 1 to 255 (see IETF RFC 8285 \[86\]).

#### 9.3.1.71 Recommended Cells for Paging

This IE contains the recommended cells for paging.

This IE is transparent to the 5GC.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| Recommended Cell List |  | 1 |  |  |
| &gt;Recommended Cell Item |  | 1..&lt;maxnoofRecommendedCells&gt; |  | Includes visited and non-visited cells, where visited cells are listed in the order the UE visited them with the most recent cell being the first in the list. Non-visited cells are included immediately after the visited cell they are associated with. |
| &gt;&gt;NG-RAN CGI | M |  | 9.3.1.73 |  |
| &gt;&gt;Time Stayed in Cell | O |  | INTEGER (0..4095) | This is included for visited cells and indicates the time a UE stayed in a cell in seconds. If the UE stays in a cell more than 4095 seconds, this IE is set to 4095. |
<!-- /table -->

|                         |                                                |
|-------------------------|------------------------------------------------|
| Range bound             | Explanation                                    |
| maxnoofRecommendedCells | Maximum no. of recommended Cells. Value is 16. |

#### 9.3.1.102 PDU Session Aggregate Maximum Bit Rate

This IE is applicable for all Non-GBR QoS flows per PDU session which is defined for the downlink and the uplink direction and is provided by the SMF to the NG-RAN node.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| PDU Session Aggregate Maximum Bit Rate |  | 1 |  | Applicable for Non-GBR QoS flows. |
| &gt;PDU Session Aggregate Maximum Bit Rate Downlink | M |  | Bit Rate 9.3.1.4 | Indicates the PDU session Aggregate Maximum Bit Rate as specified in TS 23.501 [9] in the downlink direction. |
| &gt;PDU Session Aggregate Maximum Bit Rate Uplink | M |  | Bit Rate 9.3.1.4 | Indicates the PDU session Aggregate Maximum Bit Rate as specified in TS 23.501 [9] in the uplink direction. |
<!-- /table -->

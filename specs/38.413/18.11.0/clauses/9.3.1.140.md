#### 9.3.1.140 Enhanced Coverage Restriction

This IE provides information on the restriction information of using Coverage Enhancement.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| Enhanced Coverage Restriction | M |  | ENUMERATED (restricted, ...) | Indicates whether the UE is restricted to use coverage enhancement. Value "restricted" indicates that the UE is not allowed to use coverage enhancement. |
<!-- /table -->

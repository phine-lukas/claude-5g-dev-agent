#### 9.3.1.58 UE Aggregate Maximum Bit Rate

This IE is applicable for all Non-GBR QoS flows per UE which is defined for the downlink and the uplink direction and a subscription parameter provided by the AMF to the NG-RAN node.

| &gt;UE Aggregate Maximum Bit Rate Downlink | M |  | Bit Rate 9.3.1.4 | This IE indicates the UE Aggregate Maximum Bit Rate as specified in TS 23.501 [9] in the downlink direction. |
| &gt;UE Aggregate Maximum Bit Rate Uplink | M |  | Bit Rate 9.3.1.4 | This IE indicates the UE Aggregate Maximum Bit Rate as specified in TS 23.501 [9] in the uplink direction. |

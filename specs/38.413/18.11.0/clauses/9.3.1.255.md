#### 9.3.1.255 Burst Arrival Time Window

This IE indicates the burst arrival time window of the TSC QoS flow as defined in TS 23.501 \[9\].

| IE/Group Name                   | Presence | Range | IE type and reference  | Semantics description                                                                                                                                     |
|---------------------------------|----------|-------|------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| Burst Arrival Time Window Start | M        |       | INTEGER (0..640000, …) | Start of the burst arrival time window calculated with reference to the *Burst Arrival Time* IE, expressed in units of 1 us. Integer values are negative. |
| Burst Arrival Time Window End   | M        |       | INTEGER (0..640000, …) | End of the burst arrival time window calculated with reference to the *Burst Arrival Time* IE, expressed in units of 1 us. Integer values are positive.   |

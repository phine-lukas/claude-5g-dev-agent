#### 9.3.1.225 Available RAN Visible QoE Metrics

This IE defines which RAN visible QoE metrics can be configured by the NG-RAN in the RAN visible QoE measurement.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| Application Layer Buffer Level List | O |  | ENUMERATED (true, ...) | The IE defines whether the Buffer Level can be collected as a RAN visible QoE metric by NG-RAN from UE, for DASH streaming and VR service types. |
| Playout Delay for Media Startup | O |  | ENUMERATED (true, ...) | The IE defines whether the Playout delay can be collected as a RAN visible QoE metric by NG-RAN from UE, for DASH streaming and VR service types. |

#### 9.3.1.181 NR Frequency Info

This defines the carrier frequency and bands used in a cell for a given direction (UL or DL) in FDD or for both UL and DL directions in TDD.

<!-- table -->
| IE/Group Name | Presence | Range | IE Type and Reference | Semantics Description |
| NR ARFCN | M |  | INTEGER (0.. maxNRARFCN) | RF Reference Frequency as defined in TS 38.104 [39], clause 5.4.2.1. The frequency provided in this IE identifies the absolute frequency position of the reference resource block (Common RB 0) of the carrier. Its lowest subcarrier is also known as Point A. |
| NR Frequency Band List |  | 1 |  | This IE is not used in this specification and is ignored. |
| &gt;NR Frequency Band Item |  | 1..&lt;maxnoofNRCellBands&gt; |  |  |
| &gt;&gt;NR Frequency Band | M |  | INTEGER (1.. 1024, ...) | Primary NR Operating Band as defined in TS 38.104 [39], clause 5.4.2.3. The value 1 corresponds to n1, value 2 corresponds to NR operating band n2, etc. |
<!-- /table -->

| Range bound        | Explanation                                                          |
|--------------------|----------------------------------------------------------------------|
| maxNRARFCN         | Maximum value of NRARFCNs. Value is 3279165.                         |
| maxnoofNRCellBands | Maximum no. of frequency bands supported for a NR cell. Value is 32. |

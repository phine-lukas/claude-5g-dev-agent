#### 9.3.1.9 E-UTRA CGI

This IE is used to globally identify an E-UTRA cell (see TS 36.300 \[17\]).

|----------------------|----------|-------|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IE/Group Name        | Presence | Range | IE type and reference | Semantics description                                                                                                                                       |
| PLMN Identity        | M        |       | 9.3.3.5               |                                                                                                                                                             |
| E-UTRA Cell Identity | M        |       | BIT STRING (SIZE(28)) | The leftmost bits of the *E-UTRA Cell Identity* IE correspond to the ng-eNB ID (defined in clause 9.3.1.8) and to the eNB ID (defined in clause 9.3.1.165). |

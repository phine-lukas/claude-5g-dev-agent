#### 9.3.1.75 Time Stamp

This IE contains UTC time information.

|               |          |       |                        |                                                                                                                                    |
|---------------|----------|-------|------------------------|------------------------------------------------------------------------------------------------------------------------------------|
| IE/Group Name | Presence | Range | IE type and reference  | Semantics description                                                                                                              |
| Time Stamp    | M        |       | OCTET STRING (SIZE(4)) | Encoded in the same format as the first four octets of the 64-bit timestamp format as defined in clause 6 of IETF RFC 5905 \[25\]. |

#  1 Scope

The present document specifies the stage 3 protocol and data model for the Nmbsmf Service Based Interface. It provides stage 3 protocol definitions and message flows, and specifies the API for each service offered by the MB-SMF with the exception of the MB-SMF Event Exposure service.

The 5G System stage 2 architecture and procedures are specified in 3GPP TS 23.501 \[2\] and 3GPP TS 23.502 \[3\]. The 5G Multicast-Broadcast Session Management Services for 5G System is specified in 3GPP TS 23.247 \[14\].

The Technical Realization of the Service Based Architecture and the Principles and Guidelines for Services Definition are specified in 3GPP TS 29.500 \[4\] and 3GPP TS 29.501 \[5\].

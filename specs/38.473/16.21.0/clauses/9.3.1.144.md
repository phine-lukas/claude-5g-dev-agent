#### 9.3.1.144 Burst Arrival Time

This IE indicates the Burst Arrival Time as defined in TS 23.501 \[21\].

| IE/Group Name      | Presence | Range | IE type and reference | Semantics description                                                                                                           |
|--------------------|----------|-------|-----------------------|---------------------------------------------------------------------------------------------------------------------------------|
| Burst Arrival Time | M        |       | OCTET STRING          | Encoded in the same format as the *ReferenceTime* IE as defined in TS 38.331 \[8\]. The value is truncated to 1 us granularity. |

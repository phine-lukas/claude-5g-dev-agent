#### 9.3.1.15 Transmission Bandwidth

The *Transmission Bandwidth* IE is used to indicate the UL or DL transmission bandwidth.

| IE/Group Name | Presence | Range | IE Type and Reference                                                                                                                                                                                                                      | Semantics Description                                                                                                                                                                                                                              |
|---------------|----------|-------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NR SCS        | M        |       | ENUMERATED (scs15, scs30, scs60, scs120, ...)                                                                                                                                                                                              | The values scs15, scs30, scs60 and scs120 corresponds to the sub carrier spacing in TS 38.104 \[17\].                                                                                                                                              |
| NRB           | M        |       | ENUMERATED (nrb11, nrb18, nrb24, nrb25, nrb31, nrb32, nrb38, nrb51, nrb52, nrb65, nrb66, nrb78, nrb79, nrb93, nrb106, nrb107, nrb121, nrb132, nrb133, nrb135, nrb160, nrb162, nrb189, nrb216, nrb217, nrb245, nrb264, nrb270, nrb273, ...) | This IE is used to indicate the UL or DL transmission bandwidth expressed in units of resource blocks "N<sub>RB</sub>" (TS 38.104 \[17\]). The values nrb11, nrb18, etc. correspond to the number of resource blocks "N<sub>RB</sub>" 11, 18, etc. |

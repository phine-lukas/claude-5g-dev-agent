#### 9.3.1.9 gNB-DU ID

The gNB-DU ID uniquely identifies the gNB-DU at least within a gNB-CU.

| IE/Group Name | Presence | Range | IE type and reference           | Semantics description                                                                                                       |
|---------------|----------|-------|---------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| gNB-DU ID     | M        |       | INTEGER (0 .. 2<sup>36</sup>-1) | The gNB-DU ID is independently configured from cell identifiers, i.e. no connection between gNB-DU ID and cell identifiers. |

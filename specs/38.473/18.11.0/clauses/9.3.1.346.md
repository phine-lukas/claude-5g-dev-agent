#### 9.3.1.346 LTM Reset Information

This IE contains the L2 reset configuration for the serving cell and LTM candidate cell(s).

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| Serving Cell L2 Reset Configuration | O |  | OCTET STRING | Includes the ltm-ServingCellNoResetID contained in the LTM-Config IE, as defined in TS38.331 [8], for the current serving cell. |
| LTM L2 Reset Configuration List |  | 0..1 |  |  |
| &gt;LTM L2 Reset Configuration Item |  | 1.. &lt;maxnoofLTMCells&gt; |  |  |
| &gt;&gt;Cell ID | M |  | NR CGI 9.3.1.12 |  |
| &gt;&gt;LTM L2 Reset Configuration | M |  | OCTET STRING | Includes the ltm-NoResetID IE as defined in TS38.331 [8], for the LTM candidate cell identified by the Cell ID IE. |
<!-- /table -->

| Range bound     | Explanation                                                                             |
|-----------------|-----------------------------------------------------------------------------------------|
| maxnoofLTMCells | Maximum no. of Cells configured for LTM allowed towards one UE, the maximum value is 8. |

#### 9.3.1.316 Update ThresholdMBS-List Information

This IE includes thereshold MBS related list information provided in the multicast MCCH.

| &gt;ThresholdIndex Session Item |  | 1 .. &lt;maxMBSSessionsinSessionInfoList&gt; |  |  |

#### 9.3.1.338 Aggregated PRS Resource Set List

This information element is used to indicate the aggregated PRS Resource Set List.

<!-- table -->
| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| Aggregated PRS Resource Set Item |  | 1..&lt;maxnoAggCombinations&gt; |  |  |
| &gt;DL-PRS Resource Set List |  | 1 |  |  |
| &gt;&gt;DL-PRS Resource Set Item |  | 1.. &lt; maxnoAggregatedPosPRSResourceSets&gt; |  |  |
| &gt;&gt;&gt;DL-PRS Resource Set Index |  |  | INTEGER(1..8) | This IE specifies the PRS Resource Set List's that are linked for DL-PRS bandwidth aggregation. The Integer Value defines an index to the PRS Resource Set List IE within the PRS Configuration IE (9.3.1.177) . I.e., Integer value 1 corresponds to the first entry in PRS Resource Set List IE , Integer value 2 corresponds to the second entry in PRS Resource Set List IE and so on. |
<!-- /table -->

| Range bound                       | Explanation                                                                      |
|-----------------------------------|----------------------------------------------------------------------------------|
| maxnoAggCombinations              | Maximum number of aggregated frequency layer (carrier) combinations. Value is 2. |
| maxnoAggregatedPosPRSResourceSets | Maximum no of PRS resource sets aggregated. Value is 3.                          |

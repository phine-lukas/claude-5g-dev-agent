#### 9.3.1.263 Path Switch Configuration

This IE provides information for switching to an indirect path from a direct path or from another indirect path. This IE is also used for only releasing the direct path during MP.

| IE/Group Name      | Presence | Range | IE type and reference                                                  | Semantics description                                                                                         |
|--------------------|----------|-------|------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------|
| Target Relay UE ID | M        |       | BIT STRING (SIZE(24))                                                  | Corresponds to the *targetRelayUE-Identity* contained in the *CellGroupConfig* IE, defined in TS 38.331 \[8\] |
| Remote UE Local ID | M        |       | 9.3.1.267                                                              |                                                                                                               |
| T420               | M        |       | ENUMERATED (ms50, ms100, ms150, ms200, ms500, ms1000, ms2000, ms10000) | Corresponds to the t*420* contained in the *CellGroupConfig* IE, defined in TS 38.331 \[8\]                   |

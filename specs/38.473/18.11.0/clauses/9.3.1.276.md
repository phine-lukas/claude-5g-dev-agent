#### 9.3.1.276 Timing Error Margin

This information element contains the Timing error margin for the TRP Rx TEG, or TRP Tx TEG.

|---------------------|----------|-------|---------------------------------------------------------------------------------------------------------|-----------------------|
| IE/Group Name       | Presence | Range | IE type and reference                                                                                   | Semantics description |

#### 9.3.1.330 CSI Resource Configuration

This IE contains the CSI resource configuration used for LTM.

| IE/Group Name                              | Presence | Range | IE type and reference | Semantics description                                                                                              |
|--------------------------------------------|----------|-------|-----------------------|--------------------------------------------------------------------------------------------------------------------|
| CSI Resource Configuration To AddMod List  | O        |       | OCTET STRING          | Includes the *ltm-CSI-ResourceConfigToAddModList *contained in the *LTM-Config* IE as defined in TS 38.331 \[8\].  |
| CSI Resource Configuration To Release List | O        |       | OCTET STRING          | Includes the* ltm-CSI-ResourceConfigToReleaseList *contained in the *LTM-Config* IE as defined in TS 38.331 \[8\]. |

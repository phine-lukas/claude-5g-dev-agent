#### 9.3.1.71 RRC Delivery Status

This IE provides information about the delivery status of RRC messages to the UE.

|                    |          |       |                               |                                                                  |
|--------------------|----------|-------|-------------------------------|------------------------------------------------------------------|
| IE/Group Name      | Presence | Range | IE type and reference         | Semantics description                                            |
| Delivery Status    | M        |       | INTEGER (0..2<sup>12</sup>-1) | Highest NR PDCP SN successfully delivered in sequence to the UE. |
| Triggering Message | M        |       | INTEGER (0..2<sup>12</sup>-1) | NR PDCP SN for the RRC message that triggered the report.        |

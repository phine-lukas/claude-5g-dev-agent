#### 9.3.1.255 UE Reporting Information

This IE contains the UE Reporting Information.

|                    |          |       |                                                      |                                                             |
|--------------------|----------|-------|------------------------------------------------------|-------------------------------------------------------------|
| IE/Group Name      | Presence | Range | IE type and reference                                | Semantics description                                       |
| Reporting Amount   | M        |       | INTEGER (0..64)                                      | Value 0 represents an infinite number of periodic reporting |
| Reporting Interval | M        |       | ENUMERATED (none, 0.25, 0.5, 1, 2, 4, 8, 16, 32, 64) |                                                             |

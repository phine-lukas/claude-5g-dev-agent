#### 9.3.1.62 SIType List

This IE is used by gNB-CU to provide SI list of other SI for gNB-DU.

|                      |              |                          |                           |                                                                                                                   |
|----------------------|--------------|--------------------------|---------------------------|-------------------------------------------------------------------------------------------------------------------|
| **IE/Group Name**    | **Presence** | **Range**                | **IE type and reference** | **Semantics description**                                                                                         |
| **SI type item IEs** |              | *1.. \<maxnoofSITypes\>* |                           |                                                                                                                   |
| \>SI Type            | M            |                          | INTEGER (1..32, ...)      | Indicates a certain SI type required to be broadcasted by the gNB-DU. The SI Type value of other SI starts from 2 |

|                 |                                                   |
|-----------------|---------------------------------------------------|
| **Range bound** | **Explanation**                                   |
| maxnoofSITypes  | Maximum no. of SI types, the maximum value is 32. |

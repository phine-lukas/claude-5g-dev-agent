#### 9.3.1.137 NR Carrier List

This IE indicates the SCS-specific carriers per TDD, per DL, per UL or per SUL of an NR cell.

<!-- table -->
| IE/Group Name | Presence | Range | IE Type and Reference | Semantics Description |
| NR Carrier Item |  | 1..&lt;maxnoofNRSCSs&gt; |  |  |
| &gt;NR SCS | M |  | ENUMERATED (scs15, scs30, scs60, scs120, …) | SCS for the corresponding carrier. |
| &gt;Offset to Carrier | M |  | INTEGER (0.. 2199, ...) | Offset in frequency domain between Point A (lowest subcarrier of common RB 0) and the lowest usable subcarrier on this carrier in number of PRBs (using the NR SCS IE defined for this carrier). The maximum value corresponds to 275×8−1. See TS 38.211 [33], clause 4.4.2. |
| &gt;Carrier Bandwidth | M |  | INTEGER (1.. maxnoofPhysicalResourceBlocks, ...) | Width of this carrier in number of PRBs (using the NR SCS IE defined for this carrier). See TS 38.211 [33], clause 4.4.2. |
<!-- /table -->

|                               |                                                                                                    |
|-------------------------------|----------------------------------------------------------------------------------------------------|
| Range bound                   | Explanation                                                                                        |
| maxnoofNRSCSs                 | Maximum no. of SCS-specific carriers per TDD, per DL, per UL or per SUL of an NR cell. Value is 5. |
| maxnoofPhysicalResourceBlocks | Maximum no. of Physical Resource Blocks. Value is 275.                                             |

#### 9.3.1.227 IAB Congestion Indication

This IE contains the IAB downlink congestion indication. This IE is only applicable if the UE is an IAB-MT.

| IE/Group Name | Presence | Range | IE type and reference | Semantics description |
| IAB Congestion Indication List |  | 1 |  |  |
| &gt;IAB Congestion Indication List Item |  | 1.. &lt;maxnoofIABCongInd&gt; |  |  |
| &gt;&gt;Child Node Identifier | M |  | BAP Address 9.3.1.111 | This IE identifies the child node, the link to which is congested. |
| &gt;&gt;BH RLC CH List |  | 0..1 |  |  |
| &gt;&gt;&gt;BH RLC CH List Item |  | 1.. &lt;maxnoofBHRLCChannels&gt; |  |  |
| &gt;&gt;&gt;&gt;BH RLC CH ID | M |  | BH RLC Channel ID 9.3.1.113 | This IE identifies the congested BH RLC channel over the link towards the node identified by the Child Node Identifier IE. |
<!-- /table -->

|                      |                                                                                          |
|----------------------|------------------------------------------------------------------------------------------|
| Range bound          | Explanation                                                                              |
| maxnoofIABCongInd    | Maximum no. of congestion indications, the maximum value is 1024.                        |
| maxnoofBHRLCChannels | Maximum no. of BH RLC channels allowed towards one IAB-node, the maximum value is 65536. |

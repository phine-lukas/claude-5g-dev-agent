#### 9.3.1.7 SRB ID

This IE uniquely identifies a SRB for a UE.

|               |          |       |                       |                                                                                                                          |
|---------------|----------|-------|-----------------------|--------------------------------------------------------------------------------------------------------------------------|
| IE/Group Name | Presence | Range | IE type and reference | Semantics description                                                                                                    |
| SRB ID        | M        |       | INTEGER (0..3, ...)   | Corresponds to the identities of SRB as defined in TS 38.331 \[8\]. Value 0 indicates SRB0, value 1 indicates SRB1, etc. |
